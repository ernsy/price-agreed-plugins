# Price Agreed plugins

Plugins that connect AI assistants to [Price Agreed](https://priceagreed.com):
find UK tradespeople, send them one job, compare their quotes and agree a
price. No account needed.

| Folder | For | MCP server |
|---|---|---|
| `grok-bot/` | Grok Bot and Cursor (Cursor plugin format) | `https://mcp.priceagreed.com/mcp/grok` |
| `claude/` | Claude, Cowork and Claude Code | `https://mcp.priceagreed.com/mcp/claude` |

Each folder has its own README. Both bundle the same `hire-a-tradesperson`
skill. The MCP server is documented at https://priceagreed.com/developers.

This repository is a published copy; the source lives in the Price Agreed
application repository and is copied here when it changes.
